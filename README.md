# Projeto Conta Bancária - Programação Orientada a Objetos (POO)
## Matéria P.A.(programação de Aplicativos)
## DS-SENAI/BA
Aplicação Java simples desenvolvida para simular operações bancárias básicas, demonstrando conceitos de encapsulamento, validação de regras de negócio e alteração de estado do objeto.

## Tecnologias Utilizadas
- **Linguagem:** Java
- **IDE:** IntelliJ IDEA
- **Controlo de Versão:** Git & GitHub

## Funcionalidades
- Encapsulamento dos atributos (`titular`, `numeroConta`, `saldo`).
- Métodos de manipulação de saldo (`depositar` e `sacar`) com validações de segurança.
- Método para exibição do extrato bancário no terminal.
